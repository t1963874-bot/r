## 招投标常用黑话（合规提示版）

以下术语用于理解行业沟通与合规风险，不构成任何规避监管或不当竞争建议。

- **挂网**：将招标公告、采购文件或结果在指定平台公开发布。
- **标前澄清**：投标截止前，对文件含义、技术要求或商务条款提出并答复的问题。
- **资格预审**：在正式投标前审核供应商的资质、业绩和能力。
- **废标**：某份投标因不符合实质性要求、材料缺失等原因被否决。
- **流标**：有效投标不足、需求变化等导致项目未能形成有效中标结果。
- **中标候选人**：评审后按规则推荐、等待公示或确认的供应商。
- **标书响应**：逐项说明投标方案如何满足采购文件的技术与商务要求。
- **质疑 / 投诉**：供应商对采购程序或结果提出异议的正式救济渠道。
- **围标、串标、陪标**：这些俗称通常指损害公平竞争的违法违规行为，应当避免并及时寻求合规意见。
